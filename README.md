# CogniStock

## Sistema Inteligente de Gestión de Inventario mediante Inteligencia Artificial

CogniStock es un proyecto de título orientado al desarrollo de un sistema inteligente de gestión de inventario, incorporando Inteligencia Artificial para apoyar el control, análisis y gestión de productos y existencias.
